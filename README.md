# API REST - Yacarín (Tienda Online)

Backend desarrollado para la gestión de inventario, clientes y órdenes de compra de la tienda de ropa para bebés Yacarín. Construido bajo una arquitectura de N-capas.

## 🛠 Tecnologías Utilizadas
- **Framework:** NestJS (Node.js)
- **Lenguaje:** TypeScript
- **Base de Datos:** PostgreSQL
- **ORM:** TypeORM
- **Validaciones:** class-validator & class-transformer
- **Documentación:** Swagger & Scalar
- **Despliegue:** Docker & Render.com

## ⚙️ Requisitos Previos
1. Node.js (v18 o superior)
2. PostgreSQL instalado y corriendo localmente.
